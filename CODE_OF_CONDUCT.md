# Code of conduct

We are committed to a respectful, harassment-free community for everyone. Be considerate, focus
criticism on ideas and code, assume good intent while accepting correction, and avoid personal
attacks, discriminatory language, threats, unwanted attention or publication of another person's
private information.

Project maintainers may edit or remove contributions and restrict participation when behavior is
inconsistent with these expectations. Report conduct concerns privately to a repository maintainer
through GitHub. Security reports must use the separate process in [`SECURITY.md`](SECURITY.md).

Maintainers will consider the context and impact of reported behavior, preserve confidentiality as
far as practical, and apply proportionate corrective action. Retaliation against a reporter is not
acceptable.
